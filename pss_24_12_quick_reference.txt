1 1830 Photonic Service Switch product family
1.1 1830 Photonic Service Switch product family
1.1.1 Overview
The 1830 PSS product family enables today's networks to achieve converged transparent
networking by combining Dense wavelength division multiplexing (DWDM) capabilities with Optical
Cross-connection Systems (OCS).
Available features include: a combination of WDM photonic switching and ODU electronic switching
layers, scalable product size variants from access to core, interchangeable line cards among
shelves, cross-layer capabilities, and a common network management system for photonic DWDM
functions and OTN functions. The solution addresses key network backbone challenges by
providing Layer 0, Layer 1 and Layer 2 networking capability and synergies between the layers to
assure transport at the most economical level, maximum resource optimization, optimized
wavelength filling, Service Level Agreement (SLA) guarantee, flexible client service assignment,
ultrafast restoration and coordinated network operations.
Additionally,1830 PSS provides a Metro-optimized (compact, scalable and agile) transport solution
that could help maximize revenue and Return on Investment (ROI) by accelerating services
availability, time-to-market and improve network operation efficiency.
The 1830 PSS-36 and 1830 PSS-64 Release 14.1 shelves will interwork with Release 24.12
shelves. Refer to the relevant Release 14.1 documents for information about the 1830 PSS-36 and
1830 PSS-64 shelves.
Note: Release 24.12 is not supported on the 1830 PSS-36 and 1830 PSS-64 shelves.
1830 PSS-24x
The 1830 PSS-24x platform is optimized for core and large metro packet/optical transport network
(OTN) switching applications, placing industryleading electrical switching scale at international/
national, regional and metro core network locations. It provides the scale and efficiency required to
support an evolution to 100G/400G services, enabling continued revenue streams as customers
demand more bandwidth and enterprises move toward higher capacity connectivity between their
routers and data centers. With support for 24 Tb/s of non-blocking switching capacity in a single
shelf, and upgradability to 48Tb/s capacity through interconnection of shelf pairs, the 1830 PSS-24x
offers industryleading OTN and packet switch scale, port densities, and wavelength distances, while
also using less power per bit.
1830 PSS-8x shelf and 1830 PSS-12x shelf
The 1830 PSS-8x and 1830 PSS-12x are optimized for both metro aggregation and metro core
switching applications in optical transport networks (OTNs). The platforms are designed to address
multi-layer, multiservice optical network scale and efficiency by delivering an industry-leading level
of switching in a compact footprint. By leveraging class-leading, in-house-designed silicon for both
electrical switching and DWDM interface port density and capacity, the two platforms offer a
network evolution path that enables operators to keep up with bandwidth demands while minimizing
space and power requirements.

With 4.0 Tb/s of non-blocking switching capacity in a single 10RU shelf, 16 Tb/s per 300 mm rack,
the 1830 PSS-8x provides a small form factor highcapacity metro aggregation point. With 12 Tb/s of
non-blocking switching capacity in a 21RU shelf, 24 Tb/s per 300 mm rack, the 1830 PSS-12x
offers efficient, high-capacity, any-rate switching scale in the metro core, while also using less
power per bit.
The platforms share common cards and are designed to support a wide range of client interface
types from 100 Mb/s to 400GE, coherent programmable uplinks, and 500G-capable card slots. The
1830 PSS-8x and 1830 PSS-12x thus enable a smooth transition from legacy networks to a modern
services delivery platform, including seamless scaling toward B100G services.
1830 PSI-4L and 1830 PSI-8L shelves
The 1830 PSI-4L shelf is a compact, modular shelf type under the PSI branch of the 1830 product
family, intended for WDM line system applications.
The 1830 PSI-8L shelf is a compact, modular shelf type under the PSI branch of the 1830 product
family, intended for WDM line system applications.
1830 PSS-4II shelf
The 1830 PSS-4II is a highly adaptable 2RU platform designed for metro-access aggregation,
supporting Layer 0, 1, and 2 applications.
For more detailed information on the other shelves, navigate to the respective shelf description
topics and their supported cards tables.
Unkeyed services with ROADM
There is general support for unkeyed services and used in manual or auto powered managed
networks. The new capability to support cross-connect characteristics for a dangling unkeyed cross-
connect is only realized when the add/drop cross-connect involves a topology external add/drop
port.
Packet system configurations

1.3 System profile
1.3.1 Key innovations of the 1830 PSS
The 1830 PSS platform shelves provide innovations in both, WDM optic and OTN switching
applications.
Node scalability is the ability of the system to combine up to four SWDM NEs into one cluster. In
this case, multiple NEs participate in a “cluster” arrangement with one common photonic main shelf,
while each NE remains independent and is managed separately, throughout its own management
interface.
Note: 1830 (PSS-36) and 1830 (PSS-64) are not supported in Release 24.12.
1.3.2 Introduction
1830 PSS systems can be connected to build a cluster. A cluster is a set of Network Elements
(NEs) that are connected to each other so that NEs in the cluster can manage OTs coming from
other NEs. The cluster might be hierarchical with one NE being “main” and all others being
“extension”, or flat with all NEs being able to manage OTs from other NEs in the same cluster. In
this option, the concept of main/extension disappears. They are called main NE and the “extension”
NEs are called tributary NEs.
Cluster aggregation is supported in order to extend beyond 24 shelves for Add/Drop capacity to
aggregate on a large scale traffic into an 8-degree line NE. Multiple 1830 NEs can participate in a
“cluster” arrangement, but each NE remains independent. Each NE is managed separately, through
its own management interface. Each NE has its own 24-shelf maximum size. However, NEs with
optical line resources can perform auto power management for OT line ports on other NEs. General
management functions continue to be performed by the individual NEs which contain the OTs.
For the 1830 PSI-8L, a NE can consist of up to 31 1830 PSI-8L shelves (compared to 24 for PSS).
Only homogeneous NEs are supported for the 1830 PSI-8L, meaning an 1830 PSI-8L main shelf
can support up to 30 1830 PSI-8L extension shelves.
1830 PSS supports two types of Network Elements (NEs):
• SWDM NEs, containing 1830 PSS-4, 1830 PSS-4II, 1830 PSS-8, 1830 PSS-16, 1830 PSS-16II,
1830 PSS-32, 1830 PSS-8x, 1830 PSS-12x, 1830 PSS-24x, 1830 PSI-4L and/or 1830 PSI-8L
shelves
• OCS NEs containing 1830 PSS-36 and/or 1830 PSS-64 shelves
A cluster is composed of:
• One or more OCS NEs
Each OCS NE can be built up by one main shelf and up to seven extension shelves. Each OCS
NE does support IP address on its main shelf.
• One or more SWDM NEs

1.8 1830 PSS-8
1.8.1 Overview
1830 PSS supports next-generation Wavelength Division Multiplexing (WDM) multiservice packet-
optical transport from access to core. The scalable shelf has high-performance 100G transport
drives that lower Total Cost of Ownership (TCO) and extends network life cycles.
1830 PSS-8 offers a scalable and future-proof metro platform for access and aggregation networks
supporting traditional photonic and multi-service transport as well as high capacity Metro transport
applications. It also provides a high-capacity packet, Optical Transport Network (OTN), photonic
switching, multiple shelf scaling, and is designed for deployment in Central Office and OSP
environments.
1830 PSS-8 is an agile multi-service platform in both access and aggregation. It provides a vehicle
to accelerate delivery of the high capacity service demanded by the consumer.
1830 PSS offers Generalized Multi-Protocol Label Switching/Automatically Switched Optical
Network (GMPLS/ASON) control plane intelligence for added-value applications such as advanced
restoration, resource virtualization, and cross-layer automation. Providing seamless integration into
existing assets, this enables highly resilient transport and dynamic bandwidth provisioning across
multiple transport networking layers for the highest network efficiency.
Note: In the PSS-8, PSS-16II and PSS-32 shelves, a new version of the ASWG, with a power-
limited egress amplifier, is introduced for applications without an OSC. When an ASWG pack
undergoes a cold or hard reboot the software determines whether the ASWG card is a
standard or a power limited version. This feature is also supported in the IRDM20 card.
1.8.2 Description
The 1830 PSS-8 shelf has an overall depth, including cabling and fibers, of 325 mm. It provides
four full-height or eight half-height universal service slots for boards, including optical transponders,
static CWDM filters (SFC), static DWDM filters, optical amplifiers, and more. Common parts
include: equipment controller, shelf panel, user panel, fan unit, power filter (AC/DC), and shelf
chassis. The shelf is designed for 19”, 21” and 23” racks.

1.12.1 Overview
1830 PSS-16II offers a scalable and future-proof Metro platform for access and aggregation

transport applications. It provides high-capacity packet, Optical Transport Network (OTN) and
photonic switching in a small footprint, providing 1.6T of total capacity in an 8RU chassis. It
additionally offers multiple shelf scaling and is designed for deployment in Central Office
environments.
1830 PSS-16II is an agile multi-service platform in both access and aggregation. It provides a
vehicle to accelerate delivery of the high capacity service demanded by the consumer.
It offers generalized multi-protocol label switching/automatically switched optical network (GMPLS/
ASON) control plane intelligence for added-value applications such as advanced restoration,
resource virtualization, and cross-layer automation. Providing seamless integration into existing
assets, this enables highly resilient transport and dynamic bandwidth provisioning across multiple
transport networking layers for the highest network efficiency.
1.12.2 Description
The 1830 PSS-16II shelf has an overall depth of 325 mm, including cabling and fibers. It provides 8
full-height or sixteen half-height universal service slots for boards, including optical transponders,
static CWDM filters (SFC), static DWDM filters, optical amplifiers, and more. Common parts
include: equipment controller, shelf panel, user panel, fan unit, power filter (AC/DC), and shelf
chassis. The shelf is designed for 19”, 21” and 23” racks. It supports an integrated AC/DC power
filter module. The AC power filters operate in a 1+1 protected configuration and should be greater
than 2000W. Simplified timing is required. The shelf only supports DC power for 8RU and AC/DC
for 9RU shelf options.
Note: In the PSS-8, PSS-16II and PSS-32 shelves, a new version of the ASWG, with a power
limited egress amplifier, is introduced for applications without an OSC. When an ASWG pack
undergoes a cold or hard reboot, the software determines whether the ASWG card is a
standard or a power limited version. This feature is also supported in the IRDM20 card.
The PTPIOC card supports PTP messages transportation over bi-directional OTC channel. It
supports the following working modes:
• Centralized clock mode
• Relay mode
• Lambda conversion mode
The 16DC65T card is a DC power filter card with Full-featured CRU (F-CRU) capability with an
integrated timing module on the DC power supply unit.

1.14 1830 PSS-32
1.14.1 Overview
1830 PSS-32 is quite similar to the 1830 PSS-16II with all the same attributes as described in
section 1.11 of this document with the exception of the following:
• The 1830 PSS-16II End Office Shelf provides an economical 16 slot platform with a smaller
footprint
• The 1830 PSS-32 Central Office Shelf provides a 32 slot primarily DWDM platform
1.14.2 Description
The 1830 PSS-32 shelf has an overall depth, including cabling, fibers, and an optional shelf cover
of 300mm/12in wide. It is 14 RU 621.8mm/24.48in high. An extended cover kit is available that
increases the overall depth from 300mm/12in. to 330mm/13in. creating more space when needed
to allow the use of LBOs on the face plates of the cards. The backplane provides space for: control,
management, power, and transponder-transponder communication in support of O-SNCP.

1.14.3 Key features
1830 PSS-32 increases 1830 PSS scalability and flexibility in WDM/OTN Metro applications by

line rates

optical path
• 400G wavelength distances of +2,000 km over terrestrial networks and +4,000 km over sub-sea
networks
• Industry-leading spectral efficiency and fiber capacity
• Eliminate the need to regenerate at landing sites by simplifying the interconnection of sub-sea
and terrestrial systems
• Deliver reliable, high-density, environmentally friendly multiservice transport
− Redundant control, power and timing to support high-availability networks
− Multiservice packet/OTN switching
− Large-scale 1G to 400G services transport

networking or mate-to-mate interface card protection
− High-density, small-footprint platforms with low power consumption

− Efficient bandwidth management capabilities at the 100G and sub-100G levels

and networking
− Compact, single card per degree, and integrated 9-, 20-, and 32-port integrated ROADM

consumption
− Advanced ROADM solutions based on C-F and CDC-F technologies for optimized scale and
agility
− C- plus L-band (C+L) systems to double fiber capacity
− GMPLS plane intelligence for added-value applications such as advanced restoration,
resource virtualization, and cross-layer automation
− Support for SyncE for frequency synchronization distribution and PTP synchronization

− Ultra-fast wavelength multi-layer protection and restoration

1.24.1 Overview
The Nokia 1830 PSS-24x is a member of the Nokia’s 1830 PSS-x family that is part of the Nokia’s
1830 Photonic Service Switch (PSS) portfolio. The 1830 PSS-x family of packet/OTN switches mate
switching and photonic scale, delivering multi-terabit packet/ OTN scale by leveraging the Nokia
Transport Switching Engine (TSE) and the Photonic Service Engine (PSE). The 1830 PSS-24x
platform is optimized for core and large metro optical transport network (OTN) switching
applications, placing industry-leading electrical switching scale at international/ national, regional
and metro core network locations. The 1830 PSS-24x shelf is a central office shelf providing a 24-
slot high-capacity and high-scalability switching platform with front access for all interface cards. It
provides the scale and efficiency required to support an evolution to 100G services and Beyond
100G (B100G) applications including 400GE transport and OTUCn line structure, enabling
continued revenue streams as customers demand more bandwidth and enterprises move toward
100G connectivity between their routers and data centres. With up to 24 Tb/s of electrical switching
capacity in a single shelf, the 1830 PSS-24x offers industry-leading OTN switch scale, with 1 Tb/s
per slot switching capacity and 100G-400G coherent WDM lines, while also using lowest power per
bit. On the client signal side, bit rates from 1G up to 400G are supported. This new level of
switching scale is enabled by intelligent electrical fabric design combined with WDM line interfaces
powered by the latest generation Nokia PSE-V coherent digital signal processor (DSP), and
services cards with highest client port density. Designed to support 48 Tb/s of electrical switching
capacity in a single rack, the PSS-24x is offering a network evolution path that keeps up with
bandwidth demands, drives lower Total Cost of Ownership (TCO) and extends network life cycles.
1830 PSS offers generalized multiprotocol label switching/automatically switched optical network
(GMPLS/ASON) control plane intelligence for added-value applications such as advanced
restoration, resource virtualization and cross-layer automation. Providing seamless integration into
existing assets, this enables highly resilient transport and dynamic bandwidth provisioning across
multiple transport networking layers for the highest network efficiency.
1.24.2 Description
The 1830 PSS-24x shelf is a central office shelf providing a 24 I/O slot high-capacity and high-
scalability OTN switching platform.
It provides front access for the matrix, controller, and I/O cards and rear access for power, timing
and housekeeping interfaces. This arrangement allows a clean separation of traffic fibers and
installation cables.

3.5 Transaction Language 1 (TL1) interface
3.5.1 Overview
TL1 interface provides command and response messages available for the current release of the
NE. These messages consist of input commands, command output response (successful and
unsuccessful), acknowledgement output and autonomous output.
3.5.2 TL1 Interface
TL1 is a state-less protocol, meaning a TL1 command is either accepted by the system and
processed or denied. If the command is accepted, the system will perform the requested actions
and return responses and autonomous messages are defined for the command. Subsequent TL1
commands will be independently processed solely on the current systems status.
3.5.3 TL1 Command entry
Network and User access is provided through TCP/IP on the LAN port of the LAN Switchboard. The
Direct Input Command Entry (DICE) mode is the only command entry method entered in its entirety
by the user.
3.5.4 TL1 Commands
TL1 commands are described in the respective TL1 Commands and Messages Guide.
Each command description consists of the following subsections:
• Command Header - command code and name
• Purpose - function information.
• Input Format - shows the TL1 input syntax
• Input Parameters - describes the input parameters and values used with the command.
• Successful Response Format - shows the normal (successful) response format for the
command.
• Output Parameters - describes the output parameters and parameter values.
• Unsuccessful Response Format - shows the error (unsuccessful) response format.
• Error Codes - lists the error codes associated with unsuccessful responses.
• Related Commands – a list of commands that must be executed prior to executing a command.
• Related Autonomous Responses - a list of messages, if any.

3.6 1830 PSS NETCONF/gRPC
3.6.1 Overview
1830 PSS provides an open interface supporting the NETCONF and gRPC protocols. This interface
supports a subset of the OpenConfig YANG models (http://www.openconfig.net/projects/models/).
The 1830 PSS software component providing this interface is called Open Agent.
3.6.2 Purpose
1830 PSS Open Agent with its NETCONF and gRPC interface runs in conjunction with the SNMP
and TL1 interfaces at the network element's equipment controller. These interfaces can be used in
parallel. The Open Agent makes use of the YANG models that describe the Network Element
datastore. NETCONF and gRPC are the protocols used for interaction between Open Agent
(server) and a network management system or SDN controller (client).
For more detail on NETCONF/gRPC refer to the1830 PSS NETCONF/gRPC Interface Guide.
3.6.3 NETCONF
Network Configuration Protocol (NETCONF) is a standardized IETF configuration management
protocol published in RFC 6241. It is secure, connection-oriented, and runs on top of the SSHv2
transport protocol as specified in RFC 6242 using the NETCONF Configuration Protocol over
Secure Shell (SSH) and can be used as an alternative to CLI or SNMP for managing an 1830 PSS.
NETCONF is an XML-based protocol used to configure network devices. It uses RPC messaging
for communication between a NETCONF client and the NETCONF server running on1830 PSS. An
RPC message and configuration data is encapsulated in XML. These XML documents are
exchanged between a NETCONF client and a NETCONF server in a request/response type of
interaction. The1830 PSS NETCONF interface supports both configuration and retrieval of
operational information.
Due to its nature, the data encoding scheme, on top of the RPC message, allows to customize the
Client/Server communication. Thereby, administrators can download (and upload, after editing) the
RPC message to edit the configuration statements, required for the specific client, by using a
simple text editor or XML editor. The retrieved information is in the form of a well-formed XML
document and can be exchanged for additional information processing.
3.6.4 NETCONF Operations, capabilities and datastores
The NETCONF protocol provides a small set of low-level operations to manage device
configurations and retrieve device state information. The base protocol provides operations to
retrieve, configure, copy, and delete configuration-datastores. Additional operations are provided,
based on the capabilities advertised by the device.
Descriptions of NETCONF operations, capabilities and datastores:
• Operations
NETCONF allows to retrieve data via the operations get or get-config. It allows data
manipulation via the operation edit-config. Data is managed via the operations notification or
validate feature. The NETCONF operations refer to configuration data and state data.
Configuration data is the set of writable data required to transform a system from its initial default

3.6.5 gRPC
gRPC is a second protocol approach to control network elements remotely. In gRPC a client
application can directly access a server application on a different machine as if it was a local object,
making it easier to create distributed applications and services. As in many RPC systems, gRPC is
based around the idea of defining a service, specifying the operations (methods) that can be called
remotely with their parameters and return types.
On the server side, the server implements this interface and runs a gRPC server to handle client
calls. On the client side, the client has a so-called stub that provides the same methods as the
server. gRPC clients and servers are applicable in a variety of environments - from local PCs up to
all kinds of network elements in wide area networks. They can be written in any of the supported
languages, such as: Java with clients in Go, Python, or Ruby.

3.7 Zero Touch Provisioning (ZTP)
3.7.1 Overview
The Zero Touch Provisioning (ZTP) feature for Nokia 1830 Photonic Services products is supported
on various capabilities with 1830 PSI-8L. It also provides the ability to automate the basic

3.7.2 Purpose
ZTP's purpose:
• Refers to a NE provisioning feature that is a standard practice for automatically adding NEs to a
Data Communication Network (DCN).
• It is the appropriate turn-up feature for commissioning Nokia 1830 NEs on a large scale, such as
data center of NEs, and provides the capability to add them to the network quickly and easily.
ZTP is also a feature intended to be phased in to support various provisioning and OA support

3.7.3 About ZTP
Standard Practice
For ZTP new NEs can be connected to the DCN through network or management ports. When the
new NE is then booted from factory-loaded software, a resident client advertises the NE to a
listening server configured in the DCN. The server responds and sends basic configuration and
setup data that initiates the process, resulting in an automatic upgrade, and/or provisioning, of the
NE. The NE can be partially or completely configured and commissioned, depending on the level of
customizations executed through scripting and command files automatically downloaded to the NE.
This feature thus provides the capability to eliminate the manual effort involved with installing and
turning up one or many new NEs in a DCN.
Features
The ZTP feature of Nokia 1830 products can be used as the primary method for provisioning new
NEs in the DCN. ZTP provides a capability to automate the basic provisioning, software upgrade,
and commissioning of Nokia 1830 NEs. Prior to starting ZTP the physical security of the DCN
should be in place and the network should be secured. It is important to prevent intrusion or
installation of a rogue DHCP server during ZTP. Planning should ensure that ZTP is used only in a
separate controlled, protected and supervised network zone.

4.7 1830 PSS CDC-F Connection Verification Tool (CVT)
4.7.1 Overview
The 1830 PSS CDC-F Connection Verification Tool (CVT) is a program that runs on a personal
computer and executes optical tests on the Colorless-Directionless-Contentionless, Flexible Grid
(ready) ROADM node. The tests consist of fiber path checks within the node to verify that the
connections between packs end-to-end from the fiber shuffle module have been made correctly. It
uses Command Line Interface (CLI) commands to interact with the node. The three main tests
provided are as follows:
• Fiber shuffle module (MSH8-FSM) verification tests to verify all paths through the MSH8-FSM
are intact within acceptable optical insertion loss.
• New MCS Add/Drop block tests to verify the loss of paths through and functionality of the
MCS8-16 multi-cast switch pack, verify the connection between the AAR-8A(s) and the MCS8-
16, and verify the AAR-8A(s) is connected correctly to the MSH8-FSM. Paths to already installed
degree equipment are checked. Measured path losses are checked against optical insertion loss
limits.
• New degree installation tests to verify the equipment for a new degree is connected correctly to
the MSH8-FSM, validate paths to already installed out-of-service equipment in the node, and
check the losses of these paths are within acceptable optical insertion loss limits.
C-band and L-band cards use separate add/drop, fiber shuffle, WSS, and MCS8-16 infrastructure
and are combined by the line amplifiers. The radio button is introduced to the GUI, where the user
selects the band to be tested. Based on the selection of the band, the appropriate packs will appear
in the drop-down boxes for the various network element cards. For example, when the L band is
selected, the Ingress LD drop-down box will only list the AWBING and ASWG-L cards in the NE, the
AAR-8A drop-down boxes will list the AAR2x-8AL and AARL packs in the NE, and so forth. With
regard to the Amp Arrays, the following restrictions have been enforced in the GUI: The ADx of the
FSM degree (1-4) and FSM degree (5-8) should be connected to the same AAR-type. For example,
if AD1 in degree (1-4) is connected to an AAR-8A, then AD1 in degree (5-8) should also be an
AAR-8A MCS add/drop block. The two AAR ports (AAR1 and AAR2) of an MCS card are restricted
to the same AAR-type card. The drop-down boxes of AAR-8A will reflect this restriction.
The 1830 PSS CVT tool has been enhanced to handle New Degree tests and MCS Add/Drop tests
on a system that includes in-service degrees. Test paths to the in-service ports are pared out of the
test steps to avoid error messages.

4.8 Open Agent network configuration management
4.8.1 Intention of Open Agent
1830 PSS provides an open interface supporting the NETCONF and gRPC protocols. This interface
supports a subset of the OpenConfig YANG models (http://www.openconfig.net/projects/models/).
The 1830 PSS software component providing this interface is called Open Agent.
The Open Agent is currently using the OpenConfig data models, and is also capable of supporting
other model sets, if required.
OpenConfig is a collaborative effort to develop programmatic interfaces and tools for managing
networks in a vendor-neutral way. The initial focus of OpenConfig is on compiling a consistent set of
data models (written in the data modelling language YANG) based on actual operational needs from
use cases and requirements from multiple network operators. OpenConfig includes development of
vendor-neutral APIs for declarative configuration, scalable monitoring solutions, and adoption and
native support on vendor platforms.
The following figures depict Nokia's solution of a network configuration management based on the
OpenConfig approach with Open Agent. Using NETCONF and/or gRPC a network management
system or software defined network (SDN) controller can communicate with a network element
based on YANG model structure.
Open Agent with its NETCONF and gRPC interfaces is running in conjunction with the SNMP and
TL1 interfaces at the network element's equipment controller. These interfaces can be used in
parallel. The Open Agent makes use of the YANG models that describe the network element
datastore. NETCONF and gRPC are the protocols used for interaction between Open Agent
(server) and a network management system or SDN controller (client).

4.9 Nokia WavePlanner
4.9.1 Overview
The Nokia WavePlanner is a software platform that provides network operators with a
comprehensive and easy to use set of planning, engineering, and analysis functions for WDM
networks based on the Nokia Optical portfolio. It includes a complete set of features that enable
network operators to plan their network evolution, design their network equipment, create a
connection topology, calculate optical transmission parameters, compute traffic flow routes and
analyze network protection and restoration mechanisms. WavePlanner is a Web Client- Server
application running on Windows and Linux platform. It provides users with graphical user interface
(GUI) to simplify the network design process. The rich set of API allows WavePlanner to be
integrated in an automated machine to machine network life cycle process.
WavePlanner integration with the 1830 management systems and WaveTracker OA&M support
initial system turn-up and incremental network growth. The WavePlanner tool is ideal for:
• Planning for network evolutions
• Response to RFQs
• Forecasts and orders
• Network analysis and simulation
• Network re-optimization
• Network automation
The WavePlanner tool is used for network planning and design, and it provides support for
installation and commissioning. WavePlanner is not only a traditional planning tool, but also a
network lifecycle management tool, since it is required to interact with a deployed network by
generating hardware commissioning data, network synchronization, and re-optimizing line system
and traffic.
